# EventNest Management

A full-stack event management web application for organizing, managing, and tracking events.

## Features

- 📊 Admin Dashboard
- 👥 User Management
- 📅 Event Management
- 📝 Event Registrations
- 🚀 Upcoming Events
- 🗄️ MongoDB Database Integration
- 🔗 REST API Backend
- 📱 Responsive Web Interface

## Technologies Used

### Frontend
- React
- Vite
- JavaScript
- HTML
- CSS

### Backend
- Node.js
- Express.js
- MongoDB
